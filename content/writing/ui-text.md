# Interface text

## General

- **Sentence case** everywhere: "Start experiment", not "Start Experiment".
- **Short and concrete.** Cut every word that doesn't change the meaning.
- **Address the reader as "you"**, sparingly; the Organization is "we" only in
  e-mails and documents, never in buttons.
- **No exclamation marks**, no emoji, no jokes in errors.
- **Numbers as figures**: "3 experiments", "12 Oct 2026", "3.1 %".
- **Placeholders for prices** in examples and templates are square brackets:
  "[amount] EUR".

## By element

| Element | Rule | Example |
|---|---|---|
| Button | Verb + object, 2–3 words | "Save draft", "Publish decision" |
| Link | Says where it leads | "Open experiment log" |
| Label | Noun, no colon | "Weekly budget" |
| Hint | One sentence, the format or the why | "In EUR, before VAT." |
| Placeholder | An example value, never the label | "e.g. 3 % conversion" |
| Error | What, why, what to do | "Enter a date after today, so the experiment can run." |
| Empty state | What's missing, how it gets here | "No sources yet. Add the first link from research." |
| Toast | What happened, past tense | "Draft saved." |
| Dialog title | The decision as a question | "Publish the stop decision?" |

## Status words

Use exactly the words of the badges: Hypothesis, Running, Verified signal,
Stopped, Scaling, Draft, New. See [`terminology.md`](terminology.md).
