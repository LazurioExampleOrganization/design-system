# Template: experiment update e-mail

The rendered version is [`experiment-update.html`](experiment-update.html); the
viewer shows it under **Screens → Experiment update e-mail**. Write the text
here first, then fill the HTML.

**Subject:** [Experiment name]: [verified signal / stopped / scaling] ([date])

---

Hello [first name],

[One sentence: the result and the decision.] For example: "The price
comparison test reached 3.1 % conversion on 1,240 visits, so we recommend
scaling it."

**What we tested:** [hypothesis in one sentence]
**Result:** [metric]: [value] (target [value]), verified [YYYY-MM-DD]
**Decision:** [stop / scale], [one sentence why]
**Next step:** [what happens next, who, by when]

[Name]

## Rules

- Plain text first; the HTML version only adds the layout, never more content.
- No tracking pixels, no images that carry information, no "Sent from…".
- One link at most besides the signature.
- This e-mail is a **Draft** until the responsible person says **Publish**.
  Sending it is publishing.
